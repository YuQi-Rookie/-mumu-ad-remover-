屏蔽广告域名（Hosts）
在系统 hosts 文件中添加 10+ 广告/统计域名屏蔽规则，从网络层阻断广告请求。可能影响自动更新。
去除开屏广告
清空并锁定 imageManager.json 开屏广告配置文件，同时锁定 startupImage 缓存目录，双重保障。
修改广告配置（Config）
在 config.ini 中写入 [AdConfig] 配置，强制 enable_ad=0、禁用个性化推荐和广告SDK动态加载。
禁用弹窗广告服务
替换 MuMuPlayerService.exe 为空只读文件，阻止右下角弹窗广告和推送服务。
海外版模式（去除主界面推荐）
通过 adb 在 build.prop 中写入 ro.build.version.overseas=true，屏蔽主界面轮播Banner和「每日新发现」游戏推荐。需模拟器运行中且已开启Root+可写系统盘。
禁用自动更新（可选）
禁用 MuMuPlayerUpdater.exe，防止更新后广告恢复。禁用后需手动下载更新包升级。

// HOW TO USE

      
使用教程

      
三步完成去广告，全程不到 1 分钟。

    


    

      

        
1

        
下载脚本

        
在上方配置好选项后，点击「生成去广告脚本」→ 预览代码确认无误 → 点击下载保存 .bat 文件到桌面。

      

      

        
2

        
管理员运行

        
右键点击下载的脚本文件，选择「以管理员身份运行」。脚本会自动备份并执行所有去广告操作。

      

      

        
3

        
重启模拟器

        
脚本执行完成后，关闭并重新打开 MuMu 模拟器。广告已全部去除，享受清爽体验。

  • 运行前建议关闭 MuMu 模拟器，避免文件被占用导致操作失败。
    • 
        
  • 脚本会自动备份 hosts 文件为 hosts.bak，如需还原可使用还原脚本。

// FAQ

      
常见问题

    


    

      

        

          
去广告后会影响模拟器运行吗？

          

        

        

          
不会。脚本只针对广告相关的域名、缓存目录、广告配置和广告服务进程进行处理，不触碰模拟器核心运行文件。游戏运行、网络连接、性能表现都不受影响。唯一可能受影响的是自动更新功能（如果勾选了禁用更新选项）。

        

      


      

        

          
为什么必须以管理员身份运行？

          

        

        

          
修改系统 hosts 文件（位于 C:\Windows\System32\drivers\etc\）、Program Files 目录下的程序文件，以及 config.ini 配置文件都需要管理员权限。如果不以管理员身份运行，脚本会检测到权限不足并提示退出，不会执行任何操作。

        

      


      

        

          
更新模拟器后广告又出现了怎么办？

          

        

        

          
模拟器更新可能会覆盖被替换的广告服务文件和重置 config.ini 配置。更新后只需重新运行一次去广告脚本即可。建议勾选「禁用自动更新」选项，或者在更新后重新执行脚本。hosts 屏蔽规则和开屏广告锁定通常不会被更新覆盖。

        

      


      

        

          
脚本会被杀毒软件报毒吗？

          

        

        

          
部分杀毒软件可能会对修改 hosts 文件和 Program Files 目录的批处理脚本发出警告，这是因为脚本执行了系统级修改操作，属于正常行为。脚本内容完全透明，你可以在预览区查看全部代码后再决定是否运行。如遇报毒，可选择「信任此文件」或临时关闭杀毒软件后运行。

        

      


      

        

          
我的 MuMu 安装在自定义路径，脚本还能用吗？

          

        

        

          
脚本会自动扫描 8 个常见安装路径（C/D 盘的 Program Files、Program Files (x86)、AppData\Local 等），绝大多数自定义路径都能识别。如果安装在非常特殊的路径，弹窗服务禁用部分可能无法自动执行，但 hosts 屏蔽、开屏广告去除和 config.ini 修改仍然有效。你可以手动编辑脚本，将 MUMU_DIR 变量改为你的实际安装路径。

        

      


      

        

          
V6.5.9 版本适用吗？脚本做了哪些针对性优化？

          

        

        

          
完全适用。针对 V6.x 新版做了以下优化：①数据目录使用新版路径 %APPDATA%\Netease\MuMuPlayer（无版本号后缀）；②开屏广告采用 imageManager.json 覆写+锁定方式，比单纯删目录更可靠；③新增 config.ini 的 [AdConfig] 配置写入，从配置层禁用广告；④安装目录自动检测覆盖新版路径 C:\Program Files\Netease\MuMu。选择「自动检测」即可同时尝试新旧所有路径。

        

      


      

        

          
「海外版模式」是什么？如何去除主界面的游戏推荐广告？

          

        

        

          
主界面的轮播Banner和「每日新发现」游戏推荐是 MuMu 国内版特有的运营内容，普通的 hosts 屏蔽和文件修改无法去除。最有效的方法是「海外版模式」：在模拟器的 /system/build.prop 中添加 ro.build.version.overseas=true，让模拟器认为自己是国际版，从而不加载国内运营推荐内容。

使用前需满足：①模拟器正在运行；②在 设置-其他设置-开发者选项 中开启 Root权限；③开启 磁盘共享-可写系统盘。脚本会自动通过 adb 连接模拟器并写入配置，完成后重启模拟器即可生效。如果 adb 连接失败，也可以手动在模拟器内安装 RE 文件管理器，编辑 /system/build.prop，在末尾添加 ro.build.version.overseas=true 后重启。
